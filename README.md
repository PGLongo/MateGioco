# MateGioco

App educativa di matematica per bambini di 4 anni.

## Features

- 🎈 Esercizi di somma (1-10)
- ⭐ Sistema di stelline
- 🎨 Design colorato stile Bluey
- 📱 Mobile-first responsive
- 💾 Persistenza con localStorage

## Stack

- Nuxt 3
- Vue 3 Composition API
- TypeScript
- Nuxt UI
- GitHub Pages

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run generate

# Preview production build
npm run preview
```

## Deploy

L'app viene automaticamente deployata su GitHub Pages tramite GitHub Actions.
